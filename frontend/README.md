# Frontend (React + React Router + Axios + MUI)

Базовый frontend для дипломного проекта парфюмерного интернет-магазина.

## Что уже есть

- Роутинг (`/`, `/catalog`, `/ai-consultant`, `/login`, `/register`).
- API-клиент на `axios` с `VITE_API_BASE_URL`.
- Страницы: главная, каталог, вход, регистрация, AI-консультант.
- UI на Material UI.

## Быстрый старт

1. Скопируй `.env.example` в `.env`.
2. Установи зависимости: `npm install`.
3. Запусти: `npm run dev`.

## Структура

```text
frontend/
  src/
    api/
    app/
    components/
    features/
    pages/
    theme/
```
